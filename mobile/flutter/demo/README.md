# WVAB Mobile Demo APK

`wvab-mobile-demo-arm64-v8a.apk` is the CI-built Android debug demo for 64-bit ARM devices.

- Build type: Flutter debug APK
- ABI: arm64-v8a
- Minimum Android SDK: 24
- Source: this repository's `mobile/flutter/` project
- Validation: `flutter analyze`, Flutter tests, Android host contract checks, and APK build must all pass before this file is published.

Verify the APK against `SHA256SUMS.txt` after download.

This is an assistive research prototype. It is not a certified navigation or safety device.
