# WVAB Mobile Redesign Scope

The mobile UI follows the approved WVAB mobile mockup visual language: dark navy home and assistance surfaces, green primary assistance control, light settings/detail screens, rounded cards, and accessibility-first large controls.

The interface supports English, Bangla, Russian, and Hindi. Language selection updates the visible application interface and the configured TTS language together.

Screens included in this redesign:

- Home
- Assistance / live camera
- Settings
- Language
- Connection
- Detection settings
- History
- About

Security and safety status remains explicit: Secure UDP Protocol v2 mobile streaming and object inference are not represented as connected/active until those implementations are completed and validated.
